#### **Q1: Enable Vim mode in all the software you use that supports it, such as your editor and your shell, and use Vim mode for all your text editing for the next month. Whenever something seems inefficient, or when you think “there must be a better way”, try Googling it, there probably is a better way.**

**Answer:**

We just have to install Vim in our daily use IDEs 
Currently, I use Kali Linux(Debian) shell , VS Code and Antigravity 

- To install in Linux :- <br>
1) Open The Terminal <br>
2) run the command "sudo apt update"<br>
3) then run the command "sudo apt install vim"<br>
4) to verify run "vim --version"<br>
5) You can open it by running "vim [your_filename]"<br>


- To install it in VSCode :- <br>
1) Open VSCode <br>
2) Go to the Extensions and Search Vim<br>
3) Install it and Vim will be applied Automatically <br>

- To install in Antigravity :- <br>
1) Open Antigravity <br>
2) Go to the Extensions and Search Vim <br>
3) Install it and Vim will run Automatically

#### **Q2: Complete a challenge from [VimGolf](https://www.vimgolf.com/en/).**

**Answer:**

In Vim Golf I completed a challenge which was :
[problem](https://www.vimgolf.com/challenges/9v0069dd19600000000007c9)

**Given Code**

```python
# caculate area
def calculate_area(width, height): # width, height
    return width * height # return area

area1 = calculate_area(5, 10)
area2 = calculate_area(8, 12)


```
**After Modification**

```python
def calculate_area(height, width):
    return width * height

area1 = calculate_area(5, 10)
area2 = calculate_area(8, 12)
```
