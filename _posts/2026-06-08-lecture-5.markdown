#### **Q3: One common mistake when learning Git is to commit large files that should not be managed by Git or adding sensitive information. Try adding a file to a repository, making some commits and then deleting that file from history (not just the latest commit). You may want to look at [this](https://help.github.com/articles/removing-sensitive-data-from-a-repository/).**

**Answer:** 

**Code** :- 

```bash
# make a repo
git init
# make a file and add some text to it
echo "my secret key is this : " | cat >> secret.txt
# add and commit the file
git add secret.txt
git commit -m "added secret key"

# now remove the file completely from the repository
git-filter-repo --path secret.txt --invert-paths
# risky command until you really have to delete something
```

#### **Q8: Write a script that takes a filename as an argument (`$1`) and checks whether the file exists using `test -f` or `[ -f ... ]`. It should print different messages depending on whether the file exists. See [Bash Conditional Expressions](https://www.gnu.org/software/bash/manual/html_node/Conditional-Expressions.html).**

**Answer:**
**Code** :- 


```bash
# =====1st part=======================================
git init reciepe ;
echo "A Simple Reciepe" > reciepe/reciepe.txt ;
cd reciepe ;
git add reciepe.txt ;
# =====2nd Part=======================================
git commit -m "Initial commit" ;    
git branch salty ;
git branch sweet ;
# =======3rd Part=======================================
git checkout salty ;
sed -i 's/1 cup sugar/1 cup salt/' recipe.txt ;
git add recipe.txt ;
git commit -m "Make it salty" ;
# ========4th Part=======================================
git checkout sweet ;
sed -i 's/1 cup sugar/2 cups sugar/' recipe.txt ;
git add recipe.txt ;
git commit -m "Make it sweeter" ;
# =========5th Part=======================================
git checkout master ;
git merge salty ;
git merge sweet ;
# ERROR WILL COME AS THERE WILL BE A MERGE CONFLICT
# =========6th Part=======================================
git mergetool ;
# =========7th Part=======================================
git log --graph --oneline --all ;

```
**Explanations**
- `git init` : It is used to initialize a new git repository.

- `git add` : It is used to add a file to the staging area.

- `git commit` : It is used to commit the staged files.

- `git branch` : It is used to create a new branch.

- `git checkout` : It is used to switch to a different branch.

- `git merge` : It is used to merge two branches.

- `git mergetool` : It is used to resolve merge conflicts.

- `git log` : It is used to view the commit history.
